# Bull & Bear Final GitHub Bot

Runs every 3 hours in GitHub Actions, even if your laptop/iPhone is off.

It checks the approved Pinterest sources you list, scores unseen videos for trading/Quotex relevance and Shorts-friendly duration, randomly picks from the top few, uploads to YouTube, and permanently records the source ID so the same video is not posted again.

Required GitHub Secrets: YOUTUBE_CLIENT_ID, YOUTUBE_CLIENT_SECRET, YOUTUBE_REFRESH_TOKEN.

Only use sources whose videos you own or are licensed/authorized to repost.
